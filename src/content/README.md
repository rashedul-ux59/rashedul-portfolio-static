# Case study content

Edit `projects.ts` in the parent folder to update the portfolio projects.

Each project needs a unique `slug`, title, client, discipline, year, short description, color, overview, challenge, approach steps, outcome, role, and services. The site generates a homepage card and a static detail page for each item automatically.

The three included projects were carried over from the supplied portfolio project data. Their expanded narrative sections are draft concept copy, not independently verified client results. Review and replace those details with your actual case-study facts before publishing.
